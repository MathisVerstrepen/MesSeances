## Changed

- Migrated ordinary Vue component CSS to Tailwind utilities while preserving responsive, interaction, accessibility, and reduced-motion behavior ([#39](https://github.com/MathisVerstrepen/MesSeances/pull/39))
- Centralized duplicated frontend formatting, date conversion, API error classification, and shared-theater restoration logic without changing behavior ([#40](https://github.com/MathisVerstrepen/MesSeances/pull/40))
- Consolidated duplicated backend synchronization infrastructure while preserving provider-specific request, concurrency, transaction, and migration behavior ([#43](https://github.com/MathisVerstrepen/MesSeances/pull/43))

## Added

- Administrators can edit durable movie metadata overrides that survive provider and TMDB reconciliation through a new AG Grid admin editor ([#36](https://github.com/MathisVerstrepen/MesSeances/pull/36))
- Administrators can review and correct incorrect provider movie associations through matched TMDB search and stale-safe identity correction ([#37](https://github.com/MathisVerstrepen/MesSeances/pull/37))
- A freshly migrated API remains live so an authenticated administrator can publish the first schedule snapshot on an empty database ([#41](https://github.com/MathisVerstrepen/MesSeances/pull/41))

## Improved

- Tightened sitemap discovery and indexation so only canonical, valuable routes are submitted to search engines ([#33](https://github.com/MathisVerstrepen/MesSeances/pull/33))
- Improved poster loading efficiency and layout stability with responsive TMDB sourcesets and measured LCP fetch priority ([#34](https://github.com/MathisVerstrepen/MesSeances/pull/34))
- Reduced initial frontend work by deferring route prefetch and Vuepic date-picker loading to interaction ([#42](https://github.com/MathisVerstrepen/MesSeances/pull/42))

## Fixed

- API startup failures now expose bounded structured failure details for diagnosis without logging sensitive values ([#35](https://github.com/MathisVerstrepen/MesSeances/pull/35))
- Search and filter updates no longer flood browser history while page, pagination, tab, and view navigation is preserved ([#38](https://github.com/MathisVerstrepen/MesSeances/pull/38))
